# Card-paisajes
html-css para paisajes 
Efecto de Tarjetas 3D con CSS

![image](https://github.com/user-attachments/assets/bca353b8-c530-4676-917d-8dc143aa9092)

📌 Descripción

Este proyecto muestra un efecto visual de tarjetas en 3D que giran al pasar el cursor sobre ellas, revelando información adicional en su parte posterior. El efecto está creado con HTML y CSS puro, sin necesidad de JavaScript.

✨ Características
Efecto de giro 3D suave al hacer hover

  Diseño responsive que funciona en diferentes tamaños de pantalla

  Estructura HTML semántica y CSS organizado

  Efectos visuales atractivos con sombras y transiciones

  Fácil de personalizar y extender

🛠️ Tecnologías utilizadas
HTML5

CSS3 (Flexbox, Transforms, Transitions)

🚀 Cómo usar
Clona este repositorio o descarga los archivos

Abre el archivo index.html en tu navegador

Pasa el cursor sobre las tarjetas para ver el efecto de giro

🎨 Personalización
Para personalizar las tarjetas:

Cambiar imágenes:

Reemplaza las imágenes en la carpeta img/

Actualiza las rutas en el HTML (<img src="img/nueva-imagen.jpg">)

Cambiar colores:

Edita en el CSS:

background: rgb(9, 74, 136); (fondo de la página)

background: rgb(3, 35, 54); (fondo de la cara trasera)

Modificar contenido:

Edita el texto dentro de los elementos <h3> y <p>

Actualiza los enlaces <a href="#"> con tus URLs reales

Añadir más tarjetas:

Copia y pega el bloque <div class="card">...</div>

Modifica el contenido según necesites

📝 Notas
Las imágenes deben tener una relación de aspecto adecuada para que se vean bien en las tarjetas

El efecto funciona mejor con tarjetas de tamaño similar

Para dispositivos táctiles, considera añadir JavaScript para activar el giro con un toque
